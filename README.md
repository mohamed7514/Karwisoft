# Karwisoft Marketing — gabarit de l’offre

Landing page destinée aux cabinets dentaires. Projet séparé de `../site-patient`.

## Lancer

`npm start` puis http://127.0.0.1:3100. Aucun paquet à installer.

`npm run check` vérifie la syntaxe JavaScript.

## Parcours

1. Première impression : site premium + acquisition.
2. Approche : relier le premier clic au premier contact.
3. Quatre étapes : attirer, rassurer, guider, mesurer.
4. Deux modèles : par lead (appel de 60 secondes minimum ou formulaire), ou gestion mensuelle.
5. Bonus : configuration + 30 jours de gestion Google Ads offerts à l’achat du site, budget média payé par le cabinet.
6. Résumé du modèle choisi et espace réservé à la prise de contact.

## Périmètre de cette version

Gabarit de contenu, responsive, avec maquettes HTML/CSS, progression au scroll, apparitions légères, simulation courte du parcours et sélection de formule. Les visuels définitifs et les animations immersives viendront ensuite. Aucun prix ni résultat chiffré inventé. Aucune collecte de données, aucun appel, aucune demande envoyée et aucune intégration au logiciel dentaire. Le module de prise de contact est explicitement réservé.

Fichiers à modifier : `dist/index.html` (contenu), `dist/styles.css` (mise en page), `dist/app.js` (interactions).
